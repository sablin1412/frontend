# Отчет по Контрольной работе №3

В ходе контрольной работы были выполнены задачи по практикам с 13 по 17. Целью работы являлась поэтапная разработка полноценного прогрессивного веб-приложения (PWA) для управления задачами с поддержкой офлайн-режима, синхронизацией в реальном времени и умными уведомлениями.

---

## 📋 Описание проделанной работы по практикам:

* **Практика 13:**
    * Разработан базовый интерфейс веб-приложения для ведения списка задач с использованием HTML, CSS (фреймворк Chota) и JavaScript.
    * Реализована логика добавления, отображения и удаления задач с сохранением данных в браузере с помощью `localStorage`.

* **Практика 14:**
    * Приложение преобразовано в базовое PWA.
    * Создан и настроен файл манифеста (`manifest.json`), сгенерированы и подключены иконки различных размеров для возможности установки приложения на рабочий стол ПК и домашний экран смартфонов.
    * Добавлен и зарегистрирован базовый Service Worker.

* **Практика 15:**
    * Обеспечена безопасность приложения: настроен локальный сервер с поддержкой защищенного протокола HTTPS с использованием утилиты `mkcert`.
    * Реализована архитектура **App Shell** (каркас приложения) для мгновенной загрузки базового интерфейса.
    * Настроены стратегии кэширования в Service Worker: *Cache First* для статических ресурсов (каркаса) и *Network First* для динамического контента страниц.

* **Практика 16:**
    * Разработана полноценная серверная часть на базе Node.js и фреймворка Express.
    * Внедрен протокол **WebSocket** (библиотека `Socket.IO`) для обеспечения двусторонней связи и мгновенной синхронизации новых задач между всеми подключенными клиентами в реальном времени.
    * Реализована система **Push-уведомлений**: сгенерированы VAPID-ключи, настроена отправка подписок на сервер и рассылка уведомлений о новых задачах через модуль `web-push`.

* **Практика 17:**
    * Проведена детализация функционала Push-уведомлений: добавлена форма создания задач с привязкой к конкретной дате и времени (напоминания).
    * Реализовано планирование отправки push-уведомлений на стороне сервера с использованием встроенных таймеров.
    * Добавлены интерактивные действия в уведомления: внедрена кнопка **«Отложить на 5 минут»** (Snooze), обрабатываемая через Service Worker с отправкой запроса на сервер для переноса таймера.

---

## ⚙️ Инструкция по запуску:
1. Клонировать репозиторий.
2. Установить зависимости: `npm install`
3. Сгенерировать SSL-сертификаты в корне проекта:
   `mkcert -install`
   `mkcert localhost 127.0.0.1 ::1`
4. Запустить сервер: `node server.js`
5. Открыть приложение в браузере по защищенному адресу: `https://localhost:3001`
