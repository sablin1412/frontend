## 📝 О проекте

KEYBOARD.STORE — это полнофункциональное веб-приложение для электронной коммерции с системой аутентификации, авторизации и управления доступом на основе ролей (RBAC). Проект разработан в рамках практических занятий (Контрольная работа №2) по дисциплине "Фронтенд и бэкенд разработка".

### Ключевые особенности:
- ✅ JWT аутентификация с автоматической ротацией access/refresh токенов (Axios Interceptors)
- ✅ Ролевая модель доступа (Admin, Seller, User)
- ✅ Управление товарами (CRUD)
- ✅ Управление пользователями (только Admin)
- ✅ Адаптивный темный дизайн
- ✅ Валидация форм
- ✅ Защита элементов интерфейса и маршрутов API

## 🎯 Функционал

### Для всех пользователей
- Регистрация и вход в систему
- Просмотр каталога клавиатур
- Просмотр детальной информации о товаре

### Для Seller и Admin
- Создание новых товаров
- Редактирование существующих товаров (цена, наличие, описание)

### Только для Admin
- Просмотр списка всех пользователей
- Изменение ролей пользователей
- Удаление/Блокировка пользователей
- Удаление товаров из каталога

## 🔐 Роли и права доступа

| Маршрут | Метод | Гость | User | Seller | Admin |
|---------|-------|-------|------|--------|-------|
| `/api/auth/register` | POST | ✅ | ✅ | ✅ | ✅ |
| `/api/auth/login` | POST | ✅ | ✅ | ✅ | ✅ |
| `/api/auth/refresh` | POST | ✅ | ✅ | ✅ | ✅ |
| `/api/auth/me` | GET | ❌ | ✅ | ✅ | ✅ |
| `/api/users` | GET | ❌ | ❌ | ❌ | ✅ |
| `/api/users/:id` | GET/PUT/DELETE | ❌ | ❌ | ❌ | ✅ |
| `/api/products` | GET | ❌ | ✅ | ✅ | ✅ |
| `/api/products` | POST | ❌ | ❌ | ✅ | ✅ |
| `/api/products/:id` | GET | ❌ | ✅ | ✅ | ✅ |
| `/api/products/:id` | PUT | ❌ | ❌ | ✅ | ✅ |
| `/api/products/:id` | DELETE | ❌ | ❌ | ❌ | ✅ |

**Обозначения:**
- ✅ — доступ разрешён
- ❌ — доступ запрещён

### Описание ролей:
- **Гость** — не аутентифицированный пользователь
- **User (Пользователь)** — пользователь сайта (только просмотр товаров)
- **Seller (Продавец)** — сотрудник сайта (добавление и редактирование товаров)
- **Admin (Администратор)** — управленец сайта (права продавца + управление пользователями)
