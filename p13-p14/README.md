## 📝 О проекте
Проект разработан в рамках Контрольной работы №3 (результат практических заданий 13-17) по дисциплине "Фронтенд и бэкенд разработка". Основная цель — демонстрация возможностей современных веб-технологий (Progressive Web Apps, WebSockets, Push API).

## 🚀 Функционал
* **Офлайн-режим (Service Worker):** Приложение сохраняет работоспособность без интернета, статика кэшируется с использованием архитектуры **App Shell**.
* **Установка на устройство (Web App Manifest):** Платформа распознает сайт как приложение (добавлены иконки, цвета темы, скрыт UI браузера).
* **Локальный HTTPS:** Настроен защищенный локальный сервер с помощью сертификатов `mkcert` (необходимо для работы SW и Push).
* **Real-time обновления (WebSocket):** Мгновенная синхронизация задач между открытыми вкладками/устройствами через `Socket.IO`.
* **Push-уведомления:** * Рассылка системных уведомлений о добавлении новых задач.
  * Установка таймеров на конкретное время (напоминания).
  * Возможность отложить напоминание на 5 минут (кнопка **Snooze** прямо в UI уведомления).

---

## 🛠 Технологии
* **Frontend:** HTML5, CSS (фреймворк Chota), JavaScript (ES6+).
* **PWA & API:** Service Workers, Cache API, Web App Manifest, Notification API, Push API.
* **Backend:** Node.js, Express, Socket.IO, web-push, cors.
